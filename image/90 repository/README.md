# 🧬 수렴진화 레퍼런스 풀 (`ref_pool`) 사용 가이드

이 폴더는 **Grok 일러스트 수렴진화(Convergent Evolution)**를 위한 유전자 풀(Gene Pool)입니다.

## 📂 폴더 구조
1. **`ref_pool/gemini/`** : 제미니 승인 일러스트 보관소
2. **`ref_pool/mio/`** : 미오 승인 일러스트 보관소
3. **`ref_pool/gakumas_style/`** : 학원 아이돌마스터(Gakuen Idolmaster) 화풍·채색·라이팅 기준점 보관소

---

## 💡 사용 방법 (도태 & 진화)
1. **마음에 안 드는 그림 도태시키기 (`Delete`)**
   - 윈도우 탐색기에서 `ref_pool/gemini` 또는 `ref_pool/mio` 폴더를 열고 **큰 아이콘 보기**로 확인하세요.
   - 마음에 안 드는 그림이 있으면 **그냥 삭제(`Del`)** 하시면 됩니다.
2. **새 그림 넣기**
   - 마음에 드는 새 레퍼런스 짤이나 학원 아이돌마스터 일러스트가 생기면 해당 폴더에 그냥 드래그해서 넣어두세요.
3. **진화 생성 시 자동 반영 (`evolve_pool.py`)**
   - 다음번에 일러스트를 생성할 때, `evolve_pool.py`가 **폴더에 살아남은 파일들만** 자동으로 스캔하여 Grok에 멀티 레퍼런스로 업로드합니다.
   - 새로 생성된 그림도 이 폴더에 `gen_월일_시분초_상황.png` 형태로 자동 저장되므로, 잘 나온 그림은 남겨두고 아쉬운 그림만 지워나가면 갈수록 원하는 그림체로 완벽하게 수렴합니다.
